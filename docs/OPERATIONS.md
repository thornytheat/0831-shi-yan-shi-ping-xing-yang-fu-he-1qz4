# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可签发。对仍有差异的版本可填写暂缓意见。
5. 导出复核证据并保存于交接记录。
6. 在“按委托交付”区逐委托下载交付件。客户只能拿到本委托的样品与原始测值，可自行复算；整批证据仍只在内部接口保留。
7. 同记录号跨委托测值冲突的样品显示“存疑”，随件标注涉事记录号；同委托其他样品不受影响。
8. 需要停止交付时点击“撤回授权”。撤回先入账，之后该委托的任何下载都会被拒绝（403），其他委托照常；撤回与下载同时提交时，按事务先后判定。
9. 打开历史旧批时，若来源缺少原始测值，交付件保留当时结论并标明无法复算，系统不会用新批数据补齐。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次与授权台账。恢复时使用原 Docker Compose 数据卷。
