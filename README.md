# 实验室平行样复核

材料实验室质控员可在工作台上传来源 CSV，对照规则判断差异，签发合格批次或记录暂缓意见。

按浓度量级选择相对偏差或绝对差，区分低于检出限和可定量结果。

## 启动

```sh
docker compose up --build -d --wait
```

打开 <http://localhost:18330>。页面预览带异常样例。选中阶段查看计算证据，选择可签发样例并执行批次，然后提交复核意见。执行批次后可在“按委托交付”区逐委托下载客户交付件：客户只拿到本委托的原始测值与判定参数，可自行复算；跨委托同号测值冲突的样品标存疑，同委托其他样品照常出件；撤回授权后该委托下载即被拒绝。

## 核验

```sh
docker compose exec -T app pytest -q
```
